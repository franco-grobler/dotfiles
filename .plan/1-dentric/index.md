# Dendritic Nix Refactor Plan

## Goals
- Drop GNU Stow for everything **except** the three nvim configs (`nvim/`, `nvim-dev/`, `nvim-prime/`), which stay stowed into `~/.config`.
- Home-manager owns `~/.config` for all other apps.
- **Channel strategy**: macOS (`apple-silicone`) base = `nixpkgs-unstable`; NixOS / WSL base = `nixpkgs` (stable). The opposite channel is exposed as an overlay (`pkgs.stable` on macOS, `pkgs.unstable` on NixOS).
- Single `home-manager` input following stable (`release-26.05`). Unstable is only a package overlay, not a separate HM input.
- GUI apps on macOS stay on Homebrew casks via nix-darwin `homebrew` module (as today). NixOS GUI apps via nixpkgs.
- Repo stays at `~/dotfiles`; flake path stays `~/dotfiles/nix`.

## Phase 1 — Security fixes & bug prep (no behavior change)
1. Write `Credentials.md` (see separate file) — rotate the leaked GitHub PAT in `nix/nix.conf`.
2. Remove `access-tokens = github_pat_…` line from `nix/nix.conf`.
3. Add missing `nix-snapd` flake input (referenced at `nix/lib/mksystem.nix:48` but undeclared) OR remove the snapd module call. **Recommend remove** unless you actively use snapd.
4. Remove the inline unstable cherry-pick overlay in `flake.nix` (lines 42-57) — moves to `lib/overlays.nix`.
5. Audit `zsh/.zshrc` / `zsh/.zshenv` — these contain hardcoded `/nix/store/...` paths emitted by home-manager. After migration, they're regenerated by HM from `programs.zsh.initContent`; ensure no stale sourced files remain.

## Phase 2 — Channel restructure
1. New `lib/channels.nix`:
   ```nix
   # returns per-host: { pkgs, oppositeOverlay }
   # macOS: base = nixpkgs-unstable, stable overlay
   # NixOS/WSL: base = nixpkgs (stable), unstable overlay
   ```
2. `lib/overlays.nix`: cherry-pick list, keyed by system:
   - `direnv`, `gh`, `neovim`, `opencode`, `posting`, `uv`, `gemini-cli` (the current picks), plus anything else needed.
   - Exposed via `pkgs.unstable.<name>` (NixOS) or `pkgs.stable.<name>` (macOS).
3. `home-manager` input: single, follows `nixpkgs` (stable). No second unstable HM input.
4. `mkhost.nix` takes `channelBase = "unstable" | "stable"` per host.
5. Run `nix flake lock` after flake changes.

## Phase 5 — Bring raw dotfiles under home-manager (except nvim)
For each stow directory currently at repo root, convert:

| Tool | Approach |
|---|---|
| `atuin/config.toml` | `programs.atuin.settings = { … }` (nix attrset, preserve all key values) |
| `bat/config` | `programs.bat.config = { theme = "TwoDark"; style = "…"; };` |
| `starship/starship.toml` | `programs.starship = { enable = true; settings = (builtins.fromTOML (builtins.readFile ./config/starship.toml)); }` (no rekeying) |
| `glow/glow.yml` | `xdg.configFile."glow/glow.yml".source = ./config/glow.yml;` (no HM upstream module) |
| `just/justfile` (global) | `home.file."${config.xdg.configHome}/just/justfile".source = ./config/justfile;` |
| `tmux/tmux.conf` + TPM | `programs.tmux = { enable = true; …; plugins = [ pkgs.tmuxPlugins.catppuccin … ]; };` — drops TPM entirely. Move `tmux.reset.conf` & `themes/` references inline as `extraConfig` or `xdg.configFile`. |
| `ghostty/` | `xdg.configFile."ghostty".source = ./config/ghostty;` (recursive; preserves `themes/` subdir) |
| `direnv/`, `thefuck/`, `gh/`, `lazygit/`, `lazydocker/`, `btop/`, `htop/`, `fastfetch/`, `carapace/`, `git-cliff/`, `prettierd/`, `dlv/`, `octave/`, `gcloud/`, `pnpm/`, `claude/`, `colima/`, `1Password/` | Each → `programs.*` module or `xdg.configFile .source`. Walk each dir during execution. |
| `nvim/`, `nvim-dev/`, `nvim-prime/` | **Stay stowed.** Not managed by HM. Update `.stow-local-ignore` to scope stow to these three only. |
| `homebrew/leaves.txt`, `casks.txt` | Drop — superseded by declarative `homebrew.brews`/`casks`. Optional: keep as `just brew-dump` chore. |
| `sops/age/` | Move keygen from `install.sh` into a nix-darwin activation script OR keep in `install.sh` (simplest). Keep `sops/age/.gitignore = *`. |

After this, `.stowrc` and `.stow-local-ignore` stay (for nvim); remove all other stow dirs from the repo once migrated (or leave as backups — your call).
